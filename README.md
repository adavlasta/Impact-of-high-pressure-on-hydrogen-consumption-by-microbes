# Impact-of-high-pressure-on-hydrogen-consumption-by-microbes

This package of notebooks each help you solve one step of the data processing for Microbial gas consumption experiments. 
relevant_column_extraction.ipynb -> for data pre-processing to cut and stitch data
rate_calculations.ipynb -> main part of processing: unit conversion, curve fitting and rate calculations
hydrogen_from_sulphide.ipynb -> this notebook calculates theoretically consumed hydrogen amount from sulphate concentrations measured at experiment endpoints
all_together.ipynb ->plots graphs for all variables together
